# Kleks(Kleki 开源版) 功能缺口分析 & 改进建议

日期：2026-09-27
方法：**不是凭印象**——直接读了本机 `E:\dev\klecks` 的源码（412 条语言词条 = 全部功能面）、`kl-types.ts` 的数据结构、滤镜/工具目录，并拉了 GitHub 上 **31 个 open issue** 和官方 roadmap（更新于 2026-03-22）。所有"有"/"没有"都标注了证据位置。

## 一、先纠正三个常见误解（它其实比传闻强）

| 传闻 | 实际 |
| --- | --- |
| "没有剪切蒙版 / 没有锁定透明" | ❌ 错。**图层级剪切蒙版有**（`TKlLayer.hasClipping`、`layers-ui.ts:593` 的 clippingToggle，有图标指示）。但**"锁定透明像素"只是笔刷/渐变/形状的一个选项**（`lock-alpha`，见 `brushes-ui/*.ts`），**不是图层属性**——想整层锁透明只能靠剪切蒙版变通。 |
| "没有对称绘制" | ⚠️ 半对。**对称只有 Chemy 笔刷有**（`brush-chemy-mirror-x` / `mirror-y`）。全局对称（所有画笔/工具）**没有**，GitHub #92 还在开着求。 |
| "只有 16 个图层" | ✅ 对，而且是**硬编码上限**：`kl-canvas.ts:51  export const MAX_LAYERS = 16`，PSD 导出也按 16 截。这是它跟现代软件差最远的一条。 |

顺带一提：**"恢复上次会话"是有的**（`tab-recovery-*` 全套 + IndexedDB），但**没有磁盘自动保存**——`file-no-autosave` 原文就是 "No autosave, no cloud storage"。

## 二、现有功能清单（源码实证）

**工具（7 个）**：画笔 / 油漆桶 / 渐变 / 形状 / 文字 / 抓手 / 选择
- 笔刷 8 种：pen（含圆/粉笔/书法/方头 4 种笔尖）、blend、sketchy、pixel（含抖动 Dither + 自定义像素图案）、chemy、smudge、eraser、eyedropper
- 油漆桶：容差、取样来源（全部/当前层/以上）、扩展像素、连续区域
- 渐变：线性 / 线性镜像 / 径向，角度吸附、锁定透明
- 形状：矩形 / 椭圆 / 线，描边或填充，固定 1:1，45° 吸附，自动平移
- 文字：字体、大小、行高、字距、左中右对齐、斜体、粗体、描边+填充（**对话框式，确认后被栅格化，不是文本图层**）
- 选择：矩形 / 椭圆 / 套索 / 多边形，布尔（替换/加/减），全选、反选、填充、擦除、变换（含 Warp 变形、Clone 克隆、移到图层）

**图层**：显隐、不透明度、**16 种混合模式**（全是 Canvas 原生那套）、剪切蒙版、新建/复制/删除/合并（含高级合并 = 选混合模式合并）/清空/重命名
**滤镜（19 个）**：裁剪扩展、翻转、透视、缩放、旋转、变换、亮度对比、曲线、色相饱和度、反相、移轴、转 alpha、三角模糊、USM 锐化、网格、噪点、图案、扭曲、灭点——**全部是对当前图层"应用"式（破坏性）**
**文件**：新建（含印刷 DIN 纸 / 屏幕 / 视频 / 方形预设）、导入（png/jpg/webp/PSD，可作图层或新图，可拍平）、保存 PNG/JPG/**PSD（保留图层+混合模式+剪切）**、复制/粘贴、Imgur 上传分享、浏览器存储（本地项目）、崩溃恢复
**其它**：防抖稳定器（可调）、压感开关、前后对比、像素化缩放、主题、多语言、规则三分线、Delete 清空图层

## 三、真正缺的 & 不完善的（按痛感排序）

### 🔴 结构性缺失（等于"用不起来"级别的缺口）

| # | 缺什么 | 为什么痛 | 实证 |
| --- | --- | --- | --- |
| 1 | **图层组/文件夹** | 16 层上限 + 不能分组，复杂稿根本组织不起来 | `TKlLayer` 只有 `isVisible/mixModeStr/opacity/hasClipping/image`，无 children |
| 2 | **16 层硬上限** | Krita/PS/CSP 基本是几百层起；这边 16 层就到顶 | `MAX_LAYERS = 16` |
| 3 | **图层蒙版（非破坏性）** | 只能用剪切蒙版近似，改完没法回退 | 无 `mask` 字段；PSD 导入遇 mask 直接报错 `TKlPsdError = 'mask'\|'group'\|'adjustment'\|'layer-effect'` |
| 4 | **调整图层 / 非破坏性滤镜** | 所有滤镜都是"应用即写死"，调错只能撤销或重画 | `filters-lazy.ts` 走的是 apply-to-layer |
| 5 | **全局对称绘制** | 画对称角色/图标是刚需，现在只有 Chemy 笔刷能给 | #92 开着，lang 里只有 `brush-chemy-mirror-*` |
| 6 | **图层级 alpha 锁定** | 上色/画阴影时防出界，是常用基本功 | `lock-alpha` 只在笔刷/渐变/形状的 UI 里 |

### 🟠 明显不完善（有，但不到位）

| # | 项目 | 现状 & 缺口 |
| --- | --- | --- |
| 7 | **性能 / 大画布** | 官方 roadmap 第一条就是"大图多图层渲染性能"；#181 大画布极卡、#218 求更大画布、#217 **HiDPI/Retina 下画面糊**（这条在 4K 屏上很要命） |
| 8 | **快捷键** | 只有 Ctrl+Z/Y/S/Shift+S/C/A/Shift+E + 单键 b/g/t/u/l/x/m + `[`/`]`；**没有自定义快捷键**（roadmap）、没有 H 抓手（#243）、没有图层快捷键（#225） |
| 9 | **文字工具** | 对话框式、确认后变像素；roadmap 明说要重做（"not in a dialog, usable on tablets, more fonts & typography"）；#207 字体锯齿 |
| 10 | **色板 / 调色板** | 完全没有（roadmap 里挂着）；只有色轮 + HEX |
| 11 | **笔刷引擎** | 6 种笔刷是硬编码的，**不能自定义笔刷**（CSP/Procreate 的核心竞争力）；无贴图笔尖、无散点/双笔、无真实不透明度；roadmap 要重写 |
| 12 | **导出格式** | 只有 PNG/JPG/PSD。无 WebP、无 **OpenRaster(.ora)**（roadmap）、无 SVG、无 GIF/动画 |
| 13 | **色深 / 色彩管理** | 只有 8bit sRGB，无 16bit、无 CMYK、无 ICC 配置 |
| 14 | **选区** | 无魔棒（roadmap 标 postponed）、无"按颜色选择"、无快速蒙版；变换后无法精调 |
| 15 | **动画 / 延时** | 无帧、无洋葱皮、无 GIF 导出（#121）、无 Speedpaint 延时录像（#150，官方回"以后可能"） |
| 16 | **克隆图章 / 修复 / 减淡加深** | 选择变换里有个 "Clone"，但没有真正意义上的图章工具、没有修复画笔、没有 dodge/burn |
| 17 | **贝塞尔/钢笔路径** | 无路径工具、无矢量层（#83 求贝塞尔） |
| 18 | **参考图窗口** | 无（画参考图得开另一个软件） |
| 19 | **移动端** | #189 iOS 26 顶排按钮够不到、#175 iPad Pixel 笔刷异常 |

### 🐞 已知 bug（官方 open issue，影响可靠性）

- **#101 (critical) 合并图层后图层消失**
- **#103 (critical) 随机清空画面**
- **#163 (critical) 多图层混合时像素毛刺**
- #224 窗口闲置后 Safari 出现多处故障
- #195 画笔偶尔不上色 / #232 缩小后绘制异常 / #219 用变换时 UI 缩小
- PSD 导入遇到 蒙版/图层组/调整图层/图层样式 → 直接报错或拍平（`import-psd-unsupported` / `import-psd-limited-support`）

## 四、跟现代绘画/图像软件的对比速查

| 能力 | Kleks | Krita | Photoshop | Procreate | CSP | Paint.NET |
| --- | --- | --- | --- | --- | --- | --- |
| 图层组 | ❌ | ✅ | ✅ | ✅ | ✅ | ✅ |
| 图层蒙版 | ❌ | ✅ | ✅ | ✅ | ✅ | 部分 |
| 调整图层/非破坏 | ❌ | ✅ | ✅ | 部分 | ✅ | ❌ |
| 全局对称 | ❌(仅Chemy) | ✅ | 部分 | ✅ | ✅ | ❌ |
| 自定义笔刷 | ❌ | ✅ | ✅ | ✅ | ✅ | ❌ |
| 动画/帧 | ❌ | ✅ | ✅ | ✅ | ✅ | ❌ |
| 16bit/CMYK/ICC | ❌ | ✅ | ✅ | ❌ | ✅ | ❌ |
| 魔棒选区 | ❌ | ✅ | ✅ | ✅ | ✅ | ✅ |
| 图章/修复 | ❌ | ✅ | ✅ | 部分 | ✅ | ❌ |
| 矢量/路径 | ❌ | ✅ | ✅ | 部分 | ✅ | ❌ |
| 云/协作 | ❌ | ❌ | ✅ | ❌ | ❌ | ❌ |
| **体积/上手成本** | ✅ 11MB、开页即画 | ❌ 大 | ❌ 贵重 | 仅 iPad | ❌ 贵 | 中 |

**定位结论**：Kleks 的甜点区是"**零安装、秒开、手感跟手的草图/涂鸦/上色**"，不是"完整修图/成稿工作流"。所以改进方向应该是**补上打断绘画流的那几条**，而不是去卷 PS。

## 五、建议做什么（按性价比排序）

### A. 桌面外壳层（小悠能直接做，不碰上游代码，收益立刻可见）

| 优先级 | 功能 | 理由 | 实现方式 |
| --- | --- | --- | --- |
| ⭐⭐⭐ | **本地磁盘自动保存 + 崩溃恢复** | 现在完全靠手动存，一崩全丢（源码明写 No autosave） | 主进程定时把 IndexedDB 里的项目/恢复数据导成文件写 `%APPDATA%\Kleks\autosave\`，启动时问"要不要恢复" |
| ⭐⭐⭐ | **文件关联 + 拖拽打开 + 最近文件** | 双击 png/psd 就能进来画，少一步 | `app.setAsDefaultProtocolClient` / 注册表关联 + `open-file` 事件；拖拽已有（`Drop to import`） |
| ⭐⭐ | **截图直接贴进画布** | 参考图/素材流必备 | Electron `desktopCapturer` + 剪贴板 |
| ⭐⭐ | **性能开关** | 缓解 #181/#217 大画布卡、4K 屏糊 | 启动加 `--enable-gpu-rasterization --enable-zero-copy --disable-frame-rate-limit`，并按 `devicePixelRatio` 校正 zoomFactor |
| ⭐⭐ | **单实例 + 多标签/多窗口** | 现在多开会有"同一张图在两个标签"的提示 | `requestSingleInstanceLock` + 多 BrowserWindow |
| ⭐ | 表笔侧键 = 橡皮、托盘常驻、导出 PDF/打印 | 细节体验 | Electron 原生 API |

### B. 上游代码层（要改 TypeScript 再重 build `dist`，小悠可以打 patch）

| 优先级 | 功能 | 为什么值得做 | 难度 |
| --- | --- | --- | --- |
| ⭐⭐⭐ | **全局对称绘制**（所有画笔，X/Y/四向） | #92 是最热的请求，且实现小：在落笔的采样点序列上镜像一份 | 低-中 |
| ⭐⭐⭐ | **图层级 Alpha 锁定** | 已有 brushes 里的同名逻辑，搬到 `TKlLayer` 上加个开关即可 | 低 |
| ⭐⭐ | **快捷键系统**（H 抓手、图层上下移/新建、`[` `]` 粒度、自定义） | #243/#225 + roadmap，直接提升手感 | 低-中 |
| ⭐⭐ | **色板（Palette）** | roadmap 挂着，UI 层就能做，常用色一键取 | 低 |
| ⭐⭐ | **PSD 里的蒙版/组：降级而不是报错**（拍平并提示） | 现在直接抛错，用户一脸懵 | 中 |
| ⭐ | **WebP 导出 / 加一个 OpenRaster 导入导出** | roadmap 项，格式互通 | 中 |
| ⭐ | **延时/GIF 导出**（记录每次 history 快照成帧） | #121/#150，社交分享很好用；history 已有条目结构 | 中-高 |
| ⭐ | 图层组、图层蒙版、调整图层 | 真缺，但要动渲染合成核心（`layer-compositor.ts`） | 高 |
| ⭐ | 16 层上限放开 + 大画布分块渲染 | 上层建筑，涉及 WebGL 管线重写（官方自己排在 2027 WebGPU） | 很高 |

### C. 不建议现在做

- WebGPU 渲染迁移（官方自己排到 ~2027）
- 云端协作、账号体系（跟"零安装秒开"的定位冲突）
- 修 #101/#103 那种"随机清空/合并丢层"的 critical bug——**除非能稳定复现**，否则容易越修越乱（官方标了 not reproduced）

---

## 六、小悠的一句话建议

**先做 A 档的三件（自动保存 / 文件关联 / 性能开关），再挑 B 档里的"全局对称 + 图层 alpha 锁 + 快捷键"**——这五条加起来就能把它从"不错的网页画板"变成"日常敢用的本地画图软件"，而完全不用碰它最脆弱的渲染核心。
